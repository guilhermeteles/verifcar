Arquitetura

Estrutura geral do sistema

O VerifCar é dividido em dois produtos: um app mobile para inspetores de campo e um dashboard web para gestão e inteligência. Ambos compartilham a mesma API e banco de dados.

App Mobile
Interface de campo para inspetores. Captura imagens do veículo, executa OCR e verificação biométrica do chassi, VIN e vidros. Funciona em modo offline com sincronização posterior.
HTML/CSS/JS PWA Camera API Offline-first
Dashboard Web
Central de gestão e inteligência para supervisores e gestores. Monitora operações em tempo real, analisa tendências táticas e oferece grafo de conexões investigativas.
HTML/CSS/JS Chart.js SVG Graph Canvas API
API Gateway
Camada intermediária que recebe requisições do app e do dashboard, autentica via JWT, aplica rate limiting e orquestra chamadas ao banco de dados, motor de IA e bases externas.
REST JWT TLS 1.3 Rate Limit
Motor de IA (VerifCar Neural)
Modelo treinado com 1,2M verificações. Realiza OCR de placas e VINs, análise de integridade do chassi (profundidade, espaçamento), reconhecimento de vidros e score de risco.
Vision Model OCR Scoring Inference API
Banco de Dados
Armazena verificações, veículos, inspetores, alertas e ocorrências. Dados criptografados em repouso (AES-256). Backup automático com retenção mínima de 5 anos conforme legislação.
PostgreSQL AES-256 Backup S3 Audit Log
Bases Externas
Integração com RENAVAM (consulta de veículos), Base Nacional (notificações e restrições) e SINESP (boletins de ocorrência). Todas as consultas são logadas para auditoria.
RENAVAM Base Nacional SINESP Webhook

Segurança & Conformidade

LGPD, criptografia e auditoria

O VerifCar foi projetado com privacidade e segurança desde a base, seguindo os requisitos da LGPD e padrões governamentais.

Criptografia em trânsito
TLS 1.3 obrigatório em toda comunicação. Headers de segurança: HSTS, X-Frame-Options, CSP, X-Content-Type-Options. Certificate pinning no app mobile.
Criptografia em repouso
AES-256 para todos os dados no banco de dados. Imagens capturadas encriptadas no S3. Chaves gerenciadas via KMS com rotação semestral.
Log de auditoria
Toda ação registrada: usuário, IP, timestamp, ação, recurso acessado. Retenção mínima 5 anos (legislação). Imutável — append-only com hash encadeado.
RBAC — Controle de Acesso
5 perfis: Inspetores (verificar, registrar), Investigador (busca, inteligência), Perito (detalhe, relatório), Gestor (dashboard, performance), Super Admin (tudo).
LGPD — Lei 13.709/18
Base legal Art. 7º II e VI. CPF sempre mascarado na exibição. Log de consulta obrigatório. DPO designado. Titulares podem solicitar acesso, correção ou exclusão via ouvidoria.
Integridade dos relatórios
SHA-256 calculado sobre o conjunto de dados + imagens de cada verificação. Assinatura ICP-Brasil do inspetor. Registro opcional em blockchain para imutabilidade.
